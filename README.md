# Cypress E2E Tests - Saucedemo

A Cypress end-to-end test suite for [saucedemo.com](https://www.saucedemo.com) that demonstrates login functionality and adding items to a shopping cart using the **Page Object Model** pattern.

## 📋 Project Structure

```
cypress/
├── e2e/
│   └── saucedemo.cy.js          # Main test file
├── fixtures/
│   ├── credentials.example.json  # Example credentials
│   └── credentials.json          # Real credentials (ignored by git)
├── support/
│   ├── e2e.js                    # Support file
│   └── pageObjects/
│       ├── LoginPage.js          # Login page object
│       └── InventoryPage.js      # Inventory page object
├── cypress.config.js
├── package.json
├── .gitignore
└── README.md
```
